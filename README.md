This is a Testing Template Repository for a project we are making, we are making our own web in godot wich only works in godot
and uses github repositories and downloads them, puts them in a temporary zip file in the users folder (user:// for godot), and then deleting that folder and the zip file itself
and loading the file in the repository that is called main and has a Godot `PackedScene` file extension (for example: .tscn (a scene file but human readable in its file plain text contents),
.scn (a .tscn file but binary and not human readable also good for safety on websites i guess and also its the recommended type to use for this web), .glb/.gltf (not recommended and supports only 3D
but can be used on other apps too like blender and other programs and also glb is the binary version of gltf while gltf is human readable kinda))

and also heres what the web supports:

<h1>2D Scenes/Websites</h1>
This can be good for websites and tools and whatever that are built in godot
for example: a zip extracting app

<h1>3D Scenes/Websites (can be used for games)</h1>
It also supports 3D wihout the need of doing translate and math and stuff
also it only supports godot scenes too but also can support .glb and .gltf scenes
and even <b>PackedScene</b> type of files like .scn and .tscn
